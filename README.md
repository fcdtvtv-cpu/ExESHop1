# Sales Bot

Telegram-бот продаж: каталог, услуги, автоматизация, макросы, безопасная сделка, заявки, отзывы.

## Запуск

```bash
cp .env.example .env
# заполнить BOT_TOKEN и ADMIN_ID
pip install -r requirements.txt
python run.py
```

## Меню

| Кнопка | Действие |
|--------|----------|
| 🛒 Каталог товаров | Игра → товар → заявка / безопасная сделка |
| 🛠 Заказать услугу | AI, IT, хостинг, дизайн… |
| ⚙️ Автоматизация | 6 готовых направлений |
| 🎮 Макросы | Игра → макрос |
| 🔒 Безопасная сделка | Playerok, Kwork, GGSale, FunPay |
| 💬 Техподдержка | Ссылка на продавца |
| ⭐ Отзывы | Оценки после сделок |
| ℹ️ Помощь | /help — описание всего |

## Отзывы и заявки

После оплаты продавец жмёт «Клиент оплатил» → клиенту запрос оценки 0–5 → отзыв в разделе «Отзывы».

Заявки приходят продавцу в личку.

## Настройка товаров

Файл `bot/services/catalog.py` — игры, услуги, автоматизация, макросы, ссылки площадок.
